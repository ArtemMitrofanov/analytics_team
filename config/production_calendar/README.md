# Производственный календарь РФ

Федеральная пятидневная рабочая неделя за 2013–2026 годы.
Источник XML-файлов: https://github.com/xmlcalendar/data/tree/master/ru
Загружены 2026-11-02; приложение использует локальные файлы без сетевых запросов.

Типы исключений: `1` — нерабочий день; `2` — сокращённый рабочий;
`3` — рабочий выходной. Остальные даты определяются по дню недели.
Для метрики QA любой рабочий день рассматривается целиком, 00:00–24:00.

Календарь 2026: https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2026/
Переносы 2026: постановление Правительства РФ от 24.09.2025 № 1466.
Региональные праздники не включены. Перед расчётом следующего года добавьте
его календарь: неизвестный год вызывает явное предупреждение, без подстановки
обычного расписания понедельник–пятница.
